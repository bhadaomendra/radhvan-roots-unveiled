# SEO & GEO Growth Plan — Radhvan Origins

## Goal
Turn the current single-page site into an indexable, citeable educational authority for **Cordyceps militaris** so it starts ranking for mid/long-tail keywords and is referenced by AI search engines (ChatGPT, Perplexity, Google AI Overviews, etc.).

## Current baseline
- **Google Search Console:** verified, indexed, sitemap submitted; 0 clicks, 0 impressions (2026-07-16 → 2026-08-12).
- **SEO audit:** stale scan. One known failing finding: newsletter form is client-side only and not recorded anywhere.
- **Semrush:** no existing authority/traffic for the Lovable subdomain. Keyword research shows demand in India and US for `cordyceps militaris`, `cordyceps benefits`, `cordycepin`, `cordyceps vs sinensis`, `cordyceps for skin`, `cordyceps cancer`, etc.
- **Site structure:** high-quality single page with semantic HTML, but only one indexed URL and a poetic H1 that does not include the primary keyword.

## What we will build

### Phase 1 — Technical SEO refresh (Day 1)
1. Re-run the SEO audit scan and fix any new issues.
2. Add a `public/llms.txt` file for Generative Engine Optimization.
3. Optimize homepage `<title>`, `<meta name="description">`, and the single `<h1>` to include the primary keyword while keeping the premium brand voice.
4. Add self-referencing canonical and Open Graph tags for the homepage.
5. Update the sitemap to include new routes as they are created.

### Phase 2 — Content hub pages (Day 2–3)
Create new indexable routes targeting the best opportunities from keyword research:
- `/cordyceps-vs-sinensis` — KD 16 (easy), clear comparison intent, Indian competitors already ranking.
- `/cordycepin` — KD 35 (possible), 720/mo global searches; a dedicated compound page.
- `/cordyceps-health-benefits` — cancer, mood, blood pressure, skin, and arthritis research with strong disclaimers.
- `/cordyceps-cultivation` — lab process overview targeting cultivation and quality queries.
- `/faq` — standalone FAQ page for voice/AI search snippets.

Each page will have:
- Unique title, meta description, H1, canonical, and Open Graph tags.
- A concise answer near the top for AI snippet extraction.
- Internal links to the homepage and related hub pages.
- Citations linking to PubMed/PMC research.
- Original or AI-generated botanical/scientific illustrations.
- A prominent medical disclaimer.

### Phase 3 — Authority & GEO signals (Day 4)
- Expand Organization JSON-LD with `url`, `sameAs`, `contactPoint`, and address.
- Add Article/ResearchPage structured data on new pages.
- Add an author/team section with credentials on the About area.
- Reinforce the medical disclaimer on every health-related page.
- Keep `/llms.txt` updated with all public pages.

### Phase 4 — Measure & iterate
- Submit the updated sitemap to Google Search Console.
- Monitor impressions, clicks, and average position weekly.
- Add a blog route later for ongoing content such as research summaries, cultivation updates, and product launches.

## Outcome
- 5+ indexable pages targeting real, low-to-mid difficulty keywords.
- A clear AI-readable summary of the site via `llms.txt`.
- Stronger technical SEO, E-E-A-T, and snippet-friendly content.
- A foundation to publish more educational content as the brand grows.
