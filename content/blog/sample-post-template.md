Start with two or three sentences that answer the reader's question directly. Search engines and AI assistants often quote this opening.

## Use H2 headings for the main sections

Each H2 becomes an entry in the "In this article" list, so write headings that describe the section in plain words.

### Use H3 for sub-points

Keep paragraphs short. Link to other pages on the site, for example the [Cordyceps FAQ](/cordyceps-faq) or the [cultivation training](/cultivation-training), because internal links help both readers and search engines.

## Lists, tables and images

- Bullet points are good for quick facts.
- Add an image from the editor toolbar and always fill in its description (alt text).
